判定方法

  1. 每日净申赎估算：T = Σ(当日份额变动 × 当日估算净值)，单位亿元；净值以"规模÷份额"近似。分方向呈现：上证50 / 沪深300 / 中证500 / 中证1000 / 中证2000 / 科创50 各自前5大ETF的分类净申赎。
  2. 绝对值法判定：T ≥ +100亿 → "大概率买了"；+50亿 ≤ T < +100亿 → "疑似净买入"；T ≤ -100亿 → "大概率卖了"；-100亿 < T ≤ -50亿 → "疑似净卖出"；|T| < 50亿 → "未见明显动作"。
  3. ETF份额数据于T+1披露。本展示保留历史快照，结论对应快照内的交易日，不代表今日动向。
